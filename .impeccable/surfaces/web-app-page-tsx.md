# Markets app — Default information architecture

Mode: operate.

Default home is Your OVRFLO at `/`. Navigation is Your OVRFLO, Create, and Activity at `/`, `/create/`, and `/activity/`. Create offers Self-Repaying Loan at `/borrow/` and Fixed Return at `/supply/`. Advanced is disclosure over the current destination. It does not add a Dashboard or a Markets destination. Wallet and network stay visible and secondary.

The visual system is `DESIGN.md`: cool near-white canvas, white bordered cards, navy text, cobalt actions, Schibsted Grotesk, moderate radii. Advanced uses the same tokens with denser padding. Do not restore gold-only accent, square one-bit cards, black inversion, mono-heavy or all-caps navigation, bitmap framing, or watch-wall-first navigation.
